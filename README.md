# BallRoll

**Mobile puzzle game with 100 handcrafted levels**

BallRoll is a level-based mobile puzzle game built around compact, progressively challenging stages. The project was developed as a production-ready web game and then packaged natively for iOS.

## Product Highlights

- 100 handcrafted levels
- Progressive puzzle difficulty
- Persistent player progress
- Mobile-first interaction design
- Stable lifecycle handling
- Safe-area ready mobile layout
- Release-hardened web build
- Native iOS packaging with Capacitor

## Tech Stack

`JavaScript` · `Vite` · `Capacitor` · `iOS`

## Engineering & Release Work

The project includes work across both gameplay and production readiness:

- level design and progression
- state and storage recovery
- input and focus guards
- background / foreground lifecycle handling
- relative asset-path hardening for native packaging
- automated test coverage
- native iOS project configuration
- physical-device validation
